# Sonic in World 1-1

A single-file, dependency-free HTML5 platformer: a Super Mario Bros. *World 1-1*–style
level re-skinned with **Sonic the Hedgehog** as the playable character.

## Play

Open `sonic-world-1.html` in any modern browser. No build step, no server needed.

## Controls

| Key | Action |
| --- | --- |
| ← / → | Move |
| Space / ↑ | Jump (hold for a higher jump) |
| Shift | Run / spin-dash speed |
| R | Restart level |

## Sonic-flavored twists on the Mario formula

- **Rings instead of coins.** Collect rings; `?` blocks pop out a handful.
- **Sonic damage rules.** Getting hit while holding rings scatters them instead
  of costing a life. Get hit with zero rings and you go down.
- **Spin jump.** In the air Sonic curls into his classic spin-ball.
- **Badniks.** Stomp the Motobug-style enemies Mario-style for bonus rings.
- **Goal post** at the end of the stage instead of a flagpole castle.

It's a level layout in the spirit of World 1-1 — pipes, brick rows, item blocks,
patrolling enemies, and a pit or two — so the pacing feels familiar.
